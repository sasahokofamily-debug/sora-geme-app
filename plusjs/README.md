# plusjs

SHOO KING II の追加UI・拡張機能用 JavaScript をまとめるフォルダです。

現在の主な内容:
- `current-ui-suite.js` — 現行Command UI本体
- `current-ui-extra.js` — 各サブ画面のCommand UI拡張
- `login-command-extras.js` — ログイン画面の設定/HOME導線追加
- `gacha-upgrade.js` — ガチャUI/演出拡張
- `gacha-11.js` — 11連ガチャ拡張
- `gacha-cinematic.js` — シネマティックガチャ演出
- `gacha-runtime-bridge.js` — ガチャ演出用ランタイム橋渡し

既存機能へ後付けする拡張JSは、できるだけこのフォルダへ追加します。
